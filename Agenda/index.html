Guia de Deploy Web Gratuito (Zero Custos)

Opção 1: Vercel (Recomendado - 2 minutos)

  1. Crie uma conta gratuita em vercel.com
  2. Suba esta pasta para um repositório no seu GitHub (ex: dev-agenda).
  3. No painel da Vercel, clique em "Add New... > Project" e selecione o repositório.
  4. Clique em "Deploy" (sem precisar de build command nem configurações extras).
  5. Sua agenda estará no ar com link público HTTPS gratuito!

Opção 2: GitHub Pages (Direto no GitHub)

  1. No repositório do seu GitHub onde estão os arquivos (index.html, styles.css, app.js):
  2. Acesse a aba Settings > Pages.
  3. Em Branch, escolha main e a pasta / (root) e clique em Save.
  4. Em instantes, o link https://seu-usuario.github.io/dev-agenda estará ativo.

Opção 3: Netlify Drop (Sem Git, Instantâneo)

  1. Acesse app.netlify.com/drop
  2. Arraste e solte esta pasta inteira na janela do navegador.
  3. O site é publicado imediatamente com uma URL pública grátis.
